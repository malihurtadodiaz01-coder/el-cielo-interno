# 07 · Roadmap y checklist

## Fases
| Fase | Contenido | Estimado |
|---|---|---|
| 0. Descubrimiento | Cerrar pendientes (dominio, tarifas, fotos, textos) | 1 semana |
| 1. Diseño | Tokens, héroe, componentes, prototipo móvil de Inicio | 1 semana |
| 2. Construcción MVP | Astro + 7 páginas + legales + SEO | 1–2 semanas |
| 3. Contenido y QA | Copy final, imágenes, accesibilidad, Lighthouse | 1 semana |
| 4. Lanzamiento | Dominio, HTTPS, analítica, actualizar Linktree/Instagram | 2–3 días |
| 5. Fase 2 | Reflexiones, boletín, videos, cursos, inglés | Continuo |

## Checklist de pendientes (necesito de Carlos)
- [ ] Dominio elegido y acceso al registrador
- [ ] Tarifas y opciones de pago por tipo de sesión
- [ ] Modalidad (virtual/presencial), ciudad, horarios
- [ ] Correo de contacto
- [ ] Texto limpio de "Trayectoria y propósito"
- [ ] Texto completo de la sesión de pareja (hay una parte oculta en la captura)
- [ ] Fotos: retrato en alta, 3–5 de ambiente, cielos propios
- [ ] Portada del libro en alta resolución
- [ ] Video destacado de YouTube
- [ ] Testimonios con autorización escrita (opcional)
- [ ] Registro/tarjeta profesional para mostrar credenciales
- [ ] URL correcta de Facebook
- [ ] ¿Enlace de cursos?
- [ ] Autorización para mencionar a Anamaria Aristizabal
- [ ] Revisión legal de privacidad y aviso

## Checklist técnico
- [ ] Crear proyecto Astro y repositorio
- [ ] Implementar tokens y layout base
- [ ] Componentes: Header, Footer, Hero, WhatsAppButton, Accordion, Card, Quote
- [ ] Páginas MVP y legales
- [ ] Alojar PDF del libro
- [ ] Metadatos, Open Graph, sitemap, robots, JSON-LD
- [ ] Imágenes optimizadas, fuentes autoalojadas
- [ ] Pruebas: móvil, teclado, lector de pantalla, Lighthouse
- [ ] Despliegue + dominio + HTTPS
- [ ] Analítica y eventos
- [ ] Actualizar Linktree e Instagram con el nuevo sitio

## Definición de terminado (MVP)
Todas las páginas publicadas con contenido real, sin textos de plantilla, WhatsApp funcionando en todas las páginas, Lighthouse ≥ 95, legales visibles y Linktree actualizado.
