# El Cielo Interno — sitio web

Sitio en [Astro](https://astro.build) para **El Cielo Interno**, de Carlos Eduardo Hurtado Díaz.

**Vista previa:** https://malihurtadodiaz01-coder.github.io/el-cielo-interno/

## Desarrollo
```bash
npm install
npm run dev
```

## Dónde editar
- `src/data/site.ts`: WhatsApp, redes, correo, video destacado y tarifas.
- `src/content/eventos/`: un archivo `.md` por evento (ver `_ejemplo.md.txt`).
- `docs/`: PRD, branding book, sitemap, contenido, especificación técnica, integraciones y roadmap.

## Publicación
Para publicar los cambios en GitHub Pages: `npm run deploy` (construye el sitio y lo sube a la rama `gh-pages`).
